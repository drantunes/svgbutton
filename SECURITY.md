# Security policy

Security fixes are made on the `main` branch and deployed to the hosted service. If you self-host SVG Button, use the latest commit on `main` to receive security fixes.

Report potential vulnerabilities using [GitHub's private vulnerability reporting form](https://github.com/drantunes/svgbutton/security/advisories/new). Include the affected version or commit, the impact, and steps we can use to reproduce the issue. Keep the report private while we investigate and coordinate a fix.
